Instituição: **Etec de Taboão da Serra**

### 📊 Componentes: 
Projeto desenvolvido com um proposito de ajudar os estudantes à estudarem para o Provão Paulista, por meio de quiz, simulados, ranking. O sistema de ranking é baseado em pontuação que se adquire ao realizar os simulados e os quizzes, ela pode variar dependendo de quantas questões foram acertadas ou não.

### 📕 Sistema: 
Um aplicativo focado para jovens estudantes, com uma interface simples e navegável, facilidade para realizar os simulados e quiz sobre - o Provão Paulista, e possui um sistema de ofensivas para manter o estudante focado.
